# Idea Bank

A brainstorm vault of 30+ ideas for making Memorization Station the most effective and delightful memorization tool on the planet, inspired by Michel Thomas, Anthony Metivier, and Leonardo da Vinci.

## Learning Science Features

1.  **Feynman Technique Mode**: After a card is revealed, prompt the user to "teach" the concept back in a textbox.
2.  **Michel Thomas Mode**: A guided practice session where concepts are introduced conversationally and built upon using cognates.
3.  **Interleaving Practice**: Mix cards from different decks within a single practice session to improve discrimination skills.
4.  **Retrieval Practice Variability**: Offer different ways to recall a card (e.g., from Portuguese to English, English to Portuguese, or just from the image).
5.  **Spaced Repetition Sliders**: Allow advanced users to tweak the SM-2 algorithm parameters (easiness factor, interval modifiers).
6.  **Confidence-Based Repetition**: Instead of just "Got it" / "Again," use a 4-point scale (Again, Hard, Good, Easy) for more granular SM-2 input.
7.  **Memory Palace Integration**: Add a feature to associate cards with locations in a virtual or user-defined Memory Palace.
8.  **Contextual Learning**: Show example sentences or short paragraphs using the Portuguese word.
9.  **Audio Pronunciation**: Integrate with a Text-to-Speech API to provide high-quality audio for words.
10. **Cognate Hacking Engine**: A dedicated mode that turns rule-based learning (e.g., `-tion` -> `-ção`) into a high-speed matching game.

## Creative Mnemonic & Image Tools

11. **Mnemonic Remix Sliders**: Instead of a single "Remix" button, offer sliders: "More Absurd," "More Personal," "More Vivid."
12. **Comic Strip Chaining**: A tool to link multiple cards together into a sequential story, creating a multi-panel comic strip.
13. **"Mad Libs" Mnemonic Creator**: A template-based mnemonic generator where the user fills in blanks to create a story.
14. **Image-First Creation**: Start the card creation process by generating an image, then build the mnemonic and words around it.
15. **Adversarial Image Generation**: A button that generates a *wrong* but visually similar image to test true recall vs. simple image recognition.
16. **Style Transfer**: Allow users to select "Da Vinci Sketch," "R. Crumb Ink," or "Modern Pop" for their AI-generated images.
17. **Image Editor**: A simple in-app editor to add text bubbles, arrows, or doodles on top of the generated image.
18. **Dynamic Image Prompts**: The image prompt changes slightly with each review to reinforce different aspects of the mnemonic.

## Gamification & UX

19. **Daily Quests**: "Learn 5 new verbs," "Maintain a 10-card streak."
20. **Mastery Badges**: Visual rewards for mastering specific categories (e.g., "The Conjugator," "The Cognate King").
21. **Practice "Boss Battles"**: A special session focused entirely on your 10 "hardest" cards.
22. **Zen Mode**: A minimalist, distraction-free practice mode with no timers or scores.
23. **Collectible Rarity**: Assign "rarity" to cards based on difficulty—mastering a rare card yields more XP.
24. **Deck Marketplace**: A hub for users to share or trade custom decks with unique mnemonic styles.
25. **Blueprint Mode**: A visual editor where users can "wireframe" their memory palaces with drag-and-drop card icons.

## Historical Genius Mode (Da Vinci)

26. **Mirror Writing Mode**: A fun visual filter that requires you to read the Portuguese word in reverse, stimulating different neural paths.
27. **Anatomy of a Word**: A visual breakdown of a word's etymology and "ancestor" Latin words.
28. **Sketchbook Journals**: A digital notebook where users can doodle their own mnemonics using a tablet pen.
