# Roadmap

This document outlines the potential future direction for **Memorization Station: Portuguese Edition**.

## Q3 2024: Learning Loop Polish

- **[Practice] Mastery Calculation**: Implement and display a "Mastery %" for each deck based on the SM-2 easiness factor of its cards.
- **[Practice] Session Summary**: Add a summary screen after a practice session showing stats like accuracy, new streaks, and cards learned.
- **[Creator] Deck Management**: Allow creating new decks directly from the Card Creator form.
- **[UI] Animation & Sound**: Add subtle sound effects for correct/incorrect answers and more polished "juicy" animations for card flips and button presses.

## Q4 2024: Community & Content

- **[Vault] Deck Sharing**: Implement a secure way to share decks. This could be a simple export/import of a signed JSON file or a more complex cloud-based sharing system.
- **[Vault] Search & Filtering**: Add robust search for cards within the vault and filtering by due status or mastery level.
- **[Content] Curated Starter Decks**: Add more pre-packaged decks for users (e.g., "100 Most Common Verbs," "Food & Drink").

## Q1 2025: Advanced Learning & Customization

- **[Practice] Multiple Choice Mode**: Add an alternative practice mode that presents multiple-choice questions instead of simple recall.
- **[Practice] "Feynman" Mode**: A mode where the user has to type out the mnemonic or a related concept to prove understanding.
- **[Settings] Custom Themes**: Allow users to select different color themes or even create their own.
- **[Providers] Official Qwen/OpenAI Proxy**: Release an official, easy-to-deploy local proxy server as a separate open-source project to simplify using key-based providers.

## Future Ideas (The "Big Picture")

- **[Monetization] Pro Version**: Offer a "Pro" subscription that includes features like cloud sync, unlimited AI remixes, and access to premium image generation providers.
- **[Platform] Multi-Language Support**: Abstract the core logic to support other languages, turning "Memorization Station" into a platform.
- **[AI] Mnemonic Quality Score**: Use a local AI model (e.g., via ONNX.js) to score the "quality" of a user's mnemonic based on principles of learning science (vividness, absurdity, etc.).
- **[Community] Public Deck Library**: A browsable library of high-quality, user-submitted decks.
